# 🎬 Movie Explorer — Live Demo

¡Bienvenido a la versión desplegada de **Movie Explorer**! Este proyecto es una aplicación web dinámica diseñada para explorar series de TV, construida con un enfoque en rendimiento, diseño UI premium y buenas prácticas de desarrollo.

Puedes interactuar con la aplicación en tiempo real a través del siguiente enlace:

---

## 🛠️ Tecnologías y Stack
Esta versión de producción (frontend-only) demuestra el dominio de las siguientes tecnologías:

* **Arquitectura CSS:** Metodología *Mobile First* con uso intensivo de **Custom Properties (Tokens)** para una consistencia visual total en breakpoints de 480px hasta 1400px.
* **JavaScript Moderno (ES6+):** Manipulación avanzada del DOM, manejo de promesas para el consumo de la **API de TVMaze** y lógica de filtrado dinámico.
* **Persistencia de Datos:** Implementación de `localStorage` para gestionar la biblioteca de favoritos del usuario sin necesidad de una base de datos externa.
* **UI/UX Design:** Interfaz con efectos de *Glassmorphism*, animaciones de entrada (`cardIn`) y estados vacíos (*Empty States*) optimizados.

---

## 🌟 Características Principales
* **Búsqueda Inteligente:** Filtra contenido en tiempo real consultando el endpoint de búsqueda de TVMaze.
* **Gestión de Favoritos:** Sistema completo para añadir/quitar series de una colección personal con persistencia local.
* **Diseño Responsivo:** Experiencia optimizada para dispositivos móviles, tablets y desktops mediante un sistema de grid adaptable.
* **Navegación Fluida:** Transiciones suaves y carga de esqueletos (*Skeletons*) para mejorar la experiencia de usuario percibida.
